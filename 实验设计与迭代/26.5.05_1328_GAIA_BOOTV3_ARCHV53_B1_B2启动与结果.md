- B2 dev partial 是 `41/83`，比 BOOT-V3 dev 的 `40/83` 高 `1` 题，也比 B1 dev 高 `1` 题；仍低于 baseline_dev 的 `43/83`。

- B1/B2 没有空 final，也没有 HTTP400；主要异常仍是 forced answer 与 streaming 空响应长尾。B1/B2 的 forced 数仍高：B1 test `35`、B2 test `29`，test 分数回落基本与 forced 子集低正确率一致。
