## 启动前确认

### 方法架构与版本

- `BOOT-V3 candidate`：bootstrap prompt 保留 `Goal / Allowed tools / Rules / Exit handoff / Available actions / Next` 六字段。`Allowed tools` 是每节点硬工具 allowlist，`Available actions` 只描述许可动作形式和合法跳转，`Rules` 承担本节点经验、工具选择、证据/计算/验证、answer-readiness 与 transition 判断。
- `FLOW-none`：本轮只跑 bootstrap seed skill 和 boot skill dev/test 评估。
- `ROLE-GPT54-codex-V1`：bootstrap actor 用 Codex CLI `gpt-5.4`；offline critic / offline actor 本轮不调度。
- `EXEC-QWEN3.5-9B-local-p04`：executor 走本地 Qwen3.5-9B vLLM endpoint。
- `TOOL-GAIA-V2`：`atomic_v2` 十六个原子工具。
- `ARCH-V5.3 candidate`：在 V5 any-phase / rejected-output filtering / allowed-scope feedback 基础上，新增 `NLRL_RUNTIME_HIDE_STALE_PHASE_PROMPTS=1`。初始 task prompt 与 `INIT` phase prompt 分开；离开节点后，旧节点披露替换成 inactive marker，只保留当前节点完整披露、任务说明、assistant thought 和工具结果。
- no-CONCLUDE：bootstrap skill 仍禁止生成 `CONCLUDE` 或 answer-only finalization phase。
- 答案接收阶段：`NLRL_RUNTIME_ANSWER_ACCEPTANCE_POLICY=any_phase`，任意 phase 可在 evidence/readiness 满足时输出 `<ANSWER>`。
- boot 到 A/B 链路：本轮停止在 boot_dev 生成 skill、boot_test 使用该 skill；不生成 A/B skill。
