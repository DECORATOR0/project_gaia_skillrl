## 启动前确认

### 方法架构与版本轴

- `BOOT`：无。no-skill direct baseline，不生成、不加载、不评估 skill。
- `FLOW`：direct-eval-local，依次跑 `validation_dev83` 和 `validation_test82`。
- `ROLE`：executor only。bootstrap actor、offline critic、offline actor 不参与。
- `EXEC`：`SSSAI gpt-5.2`，`responses_sse`。
- `TOOL`：`atomic_v2`。
- `ARCH`：current direct executor prompt。direct run 没有 phase graph，也没有 CONCLUDE phase。
- 答案接收：direct executor 任意步 `<ANSWER>` 即停止；max steps 后 runtime 追加 forced answer prompt。
- skill 关系：baseline 与 skill 无关，不读取 `initial_skill_path`，不走 bootstrap 到 A/B 链路。

### 上下文与预算

- 数据集：`gaia_2023_all_validation_dev_tasks.json`、`gaia_2023_all_validation_test_tasks.json`。
- 并发：`NLRL_RUNTIME_TASK_CONCURRENCY=20`，`NLRL_LLM_MAX_CONCURRENT_REQUESTS=20`。
- 最大 executor step：`40`。这是 upper-bound 复跑；旧 GPT-5.2 reference 和当前 9B baseline 是 24 step。
- forced answer：保留。若 40 step 仍无 answer，会追加一次 forced answer call。
- truncation：`NLRL_RUNTIME_MAX_CONTEXT_CHARS=0`，不做字符截断；GPT-5.2 走 Responses，不启用 Qwen tokenizer token guard。
- output：`NLRL_EXECUTOR_MAX_TOKENS` 不设置，沿用 Responses endpoint 默认输出上限。
- reasoning：`NLRL_EXECUTOR_REASONING_EFFORT=xhigh`。
- timeout/retry：`NLRL_EXECUTOR_TIMEOUT_SECONDS=900`，`NLRL_LLM_MAX_RETRIES=7`，`NLRL_LLM_RETRY_MAX_DELAY_SECONDS=90`，避免复现旧 dev ReadTimeout 污染。
- partial/tail：本脚本顺序跑 dev 再跑 test，没有 partial-tail 提前收尾；若进程异常退出，按已落盘 state 另行恢复或补跑。
