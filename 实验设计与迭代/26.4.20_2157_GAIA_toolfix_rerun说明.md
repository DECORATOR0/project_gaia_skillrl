# GAIA 工具层修复与复跑说明

时间：2026-04-20 21:57

关联分析：

## 目标

这次修改只处理工具层问题，不处理 executor 的 phase 行为和 `<ARGS>` 解析策略。

## 修复项

### 1. 附件路径解析保留软链接文件名

位置：`/data/xsy/project_gaia_skillrl/gaia_skillrl/tools.py`

原实现会在 `_resolve_workspace_path()` 中直接对相对路径做 `.resolve()`。  
GAIA 任务附件很多是带扩展名的软链接，解析后会落到 dataset cache 的 blob 文件名，扩展名丢失。

直接影响：
- 图片附件 MIME 可能从 `image/png` 退化成 `application/octet-stream`
- Excel 附件后缀会变成空字符串，`read_table` 会报 `Unsupported table format`

当前改法：
- 路径归一化改为保留软链接逻辑文件名，只做绝对路径规范化
- 工具读取时继续使用任务目录里的逻辑路径

### 2. `read_table` 增加无后缀内容探测

位置：`/data/xsy/project_gaia_skillrl/gaia_skillrl/tools.py`

原实现只按后缀分发：
- `.csv` -> `pd.read_csv`
- `.xlsx/.xls/.xlsm` -> `pd.read_excel`

当前改法：
- 原有后缀分支保留
- 无后缀或未知后缀时，先尝试 `pd.read_excel`，再尝试 `pd.read_csv`
- 返回结果里补充 `format` 字段，记录最终识别到的格式

### 3. `run_python` 工作目录切到任务目录

位置：`/data/xsy/project_gaia_skillrl/gaia_skillrl/tools.py`

原实现固定在 repo 根目录执行 Python 片段。  
模型一旦写相对文件名，附件题就容易遇到 `FileNotFoundError`。

当前改法：
- 优先使用 `active_task_data_dir`
- 没有任务目录时退回 `active_skill_dir`
- 再退回 `workspace_root`
- 同时把 `workspace_root` 注入 `PYTHONPATH`，保留导入项目模块的能力

### 4. web 请求统一走更完整的浏览器化 Session

位置：`/data/xsy/project_gaia_skillrl/gaia_skillrl/tools.py`

涉及函数：
- `web_search` 的 DuckDuckGo HTML fallback
- `fetch_url`
- `html_extract`

原实现的请求头只有一个简单 `User-Agent`。  
当前改法：
- 新增统一 `requests.Session()`
- 默认 headers 增加 `Accept`、`Accept-Language`、`Cache-Control`、`Pragma`、`Upgrade-Insecure-Requests`
- 统一通过 `_web_get()` 发起请求
