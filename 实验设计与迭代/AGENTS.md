# AGENTS.md

## 实验设计与迭代 Directory Rules

- 本目录新增文档统一使用 `YY.M.D_HHMM_标题.md` 命名，时间前缀精确到分钟。
- 时间前缀是必填项，不要在本目录新增没有时间前缀的文档。
- 时间前缀使用文档创建或落稿时的实际时间；如果只是小修，不必因为修改时间变化而重命名。
- 标题部分直接描述主题，保持简洁，沿用本目录现有命名风格。
- 如果已有同主题文档，优先新建带新时间前缀的文档，除非任务明确要求续写原文。
- 如果后续在本目录生成配套的 `pdf`、`pptx` 或其他导出文件，文件名前缀也应沿用同样的 `YY.M.D_HHMM_标题` 规则。
- 写报告或索引文档时，如果单个字段内容很长（尤其绝对路径、hash、命令、JSON 片段），避免塞进 markdown 表格单元格；优先改用对象分块、列表或代码块，让长内容独占一行，防止预览列宽压缩成竖排。
