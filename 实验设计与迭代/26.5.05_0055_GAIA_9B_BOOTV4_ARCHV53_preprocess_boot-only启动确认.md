## 启动前确认

### 方法架构与版本

- `BOOT-V4 candidate`：bootstrap 输入先经过强模型预处理。每道题追加一个短 `preprocess_note`，内容只覆盖可能的工具调用顺序、证据来源、计算/验证流程和答案格式检查；不做聚类，不生成复杂字段。
- `BOOT-V4` 继续沿用 `BOOT-V3` 的 seed skill 生成口径：`Allowed tools` 是硬 allowlist，`Available actions` 是许可动作菜单，`Rules` 写节点经验和软判断。
- `FLOW-none`：只跑 bootstrap seed skill 与 boot skill dev/test 评估。
- `ROLE-GPT54-codex-V1`：bootstrap 预处理和 bootstrap actor 均使用 Codex CLI `gpt-5.4`。
- `EXEC-QWEN3.5-9B-local-p04`：executor 走本地 Qwen3.5-9B vLLM endpoint。
- `TOOL-GAIA-V2`：`atomic_v2` 十六个原子工具。
- `ARCH-V5.3 candidate`：`NLRL_RUNTIME_HIDE_STALE_PHASE_PROMPTS=1`，离开节点后旧节点披露替换成 inactive marker。
- no-CONCLUDE：bootstrap skill 仍禁止生成 `CONCLUDE` 或 answer-only finalization phase。
- 答案接收阶段：`NLRL_RUNTIME_ANSWER_ACCEPTANCE_POLICY=any_phase`。
- boot 到 A/B 链路：本轮停止在 boot_dev 生成 skill、boot_test 使用该 skill；不生成 A/B skill。
