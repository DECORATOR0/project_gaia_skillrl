## 当前推荐使用顺序

### 1. 和 EvoSkill / skill 论文比较

优先级：

1. OfficeQA `evoskill_corpus`：最直接对齐 EvoSkill；数据、scorer、切分、corpus 口径已补齐。
2. SealQA：可全量评分，题量适中，环境简单；适合做检索/长上下文/鲁棒问答方向。
3. BrowseComp：题量大、流行度高，但必须接搜索/浏览；无浏览 baseline 只能作 sanity check。
4. SkillsBench：skill 原生语义强；Docker 权限修好后值得优先跑。

### 2. 工具 / 环境交互类

优先级：

1. tau2 retail/airline：有 train/test，工具环境清楚，和 agent tool-use 论文口径接近。
2. SQLBench：环境稳定、评分确定，适合检验 skill 是否能沉淀 SQL 规划和 schema inspect 习惯。
3. BrowserGym MiniWoB：轻量浏览器动作已通，WebArena/WorkArena 待服务。
4. WebShop：小 text env 可用，原生 WebShop 依赖较重。

### 3. 诊断与回归

优先级：

1. GAIA：当前主线，继续保留作为综合代理能力评测。
2. EO / Earth-Bench：保留为历史回归和工具链压力测试。
3. AgentBench OS / Terminal-Bench / SkillsBench native：Docker 权限解决后再进入正式队列。
