## 方法架构与六轴

- BOOT：BOOT-V3 生成的 no-CONCLUDE skill 作为基础 skill。
- FLOW：single-skill local eval；本轮不跑 bootstrap，不跑 offline critic/actor，不做 B1/B2 自动再强化。
- ROLE：当前 Codex 会话手工改写 skill；使用 B2 权限范围，可改 phase rules、`Next:` 边顺序、allowlist 和图约束表达。
- EXEC：Qwen3.5-9B-local 作为 GAIA executor。
- TOOL：`atomic_v2` tool profile；web/search 走项目 `search_runtime.json` 的代理；vision/audio/工具服务走 `NLRL_TOOL_BASE_URL`。
- ARCH：ARCH-V5.3；no-CONCLUDE；runtime `answer_acceptance_policy=any_phase`；任何 phase 都可输出非空 `<ANSWER>` 并被接受。

答案接收阶段：

- skill 内没有 `CONCLUDE` phase。
- runtime 接受任意 phase 的非空 `<ANSWER>`。
- 最大执行步数为 24，超过后 runtime 触发 forced answer step。

生成链路：

1. BOOT-V3 boot_dev 生成初始 skill。
2. 当前 Codex 会话读取 BOOT/B1/B2 skill 与 dev 轨迹，提炼规则级失败类型。
3. 当前 Codex 会话手工产出 manual skill。
4. manual skill 直接作为 initial skill 跑 dev/test eval。
