# Markdown 表格列宽测试

用途：测试 `cweijan.vscode-office` / Vditor Markdown 预览里，长路径三列表格能否用 HTML 控制列宽。

## 结论待肉眼确认

- 如果下面的 HTML 表格列宽正常，后续长路径表格可以用 HTML `<table>`。
- 如果下面的 HTML 表格仍被挤压，说明 Vditor 会覆盖或清理列宽样式，长路径入口继续用条目列表。

## 普通 Markdown 表格

| 用途 | 文件 | 何时打开 |
| --- | --- | --- |
| 后台实验进程登记 | `/data/xsy/活的进程.csv` | 发起新后台实验前刷新已有 PID；启动后写入 PID、cwd、run_dir、command、log_path；确认结束后更新状态 |
