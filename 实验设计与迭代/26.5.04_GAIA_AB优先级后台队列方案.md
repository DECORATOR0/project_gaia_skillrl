## 目标

把 2026-05-03 no-trunc budget matrix 选出的配置按优先级排成无人值守队列。4 张 A100 分成两组：

- 8B：2 张卡，跑 `Qwen3-8B-local`
- 9B：2 张卡，跑 `Qwen3.5-9B-local`

每个优先级配置在 8B 和 9B 上使用相同 executor budget。单个模型/单个配置包含 6 个实验：

1. `boot_dev`：fresh bootstrap skill + validation_dev83
2. `boot_test`：使用 bootstrap skill 跑 validation_test82
3. `A_offline_actor`：boot_dev 状态进入 full critic/actor，生成 A skill
4. `B_offline_actor`：boot_dev 状态进入 sharded critic/actor，生成 B skill
5. `A_dev`、`A_test`
6. `B_dev`、`B_test`

所以一个配置横跨 8B+9B 时，共 12 个实验。队列总控按配置优先级推进；8B worker 和 9B worker 各自顺序跑，某一边先结束就进入下一优先级，另一边继续完成当前配置。

## 当前上下文口径

当前 vLLM 服务参数按进程命令确认：

- 8B：`Qwen3-8B-local`，`--max-model-len 40960`，`--max-num-seqs 128`

配置名里的含义：

- `cap49152`：实验脚本里的 `NLRL_RUNTIME_MAX_CONTEXT_CHARS=49152`，是输入消息内容字符预算；由 `agent_loop._fit_messages_to_budget` 执行。
- `nocap`：`NLRL_RUNTIME_MAX_CONTEXT_CHARS=0`，不做 runtime 输入字符裁剪。

- `think_unlimited`：不传 thinking token budget。
- `out8k` / `out12k`：`NLRL_EXECUTOR_MAX_TOKENS=8192/12288`。
- `out_unlimited`：不传 executor `max_tokens`。

注意：8B 的 vLLM 总上下文是 40960 token，9B 是 49152 token；`cap49152` 控的是进入 executor 之前的字符预算，不等同于 vLLM 的 token 上限。

## 调度规则

- 总控脚本：`/data/xsy/project_gaia_skillrl/scripts/run_gaia_ab_priority_master_20260504.py`
- 子队列脚本：`/data/xsy/project_gaia_skillrl/scripts/run_gaia_fresh_bootstrap_ab_tail_queue.py`
- 8B 默认端点：`http://127.0.0.1:8102/v1,http://127.0.0.1:8101/v1`
- 9B 默认端点：`http://127.0.0.1:8110/v1,http://127.0.0.1:8103/v1`
- 子队列 lane 映射：`remote0,remote1,remote2,remote3 = endpoint0,endpoint1,endpoint1,endpoint0`
- 子队列并发：默认 `GAIA_AB_PRIORITY_CHILD_CONCURRENCY=20`。
- eval wave：默认 `GAIA_AB_PRIORITY_SERIALIZE_EVAL_WAVES=1`，A_dev/A_test 与 B_dev/B_test 分波跑，避免两路 `c20` 同时打到同一 endpoint。
- tail 接受：默认 `GAIA_AB_PRIORITY_TAIL_THRESHOLD=3`、`GAIA_AB_PRIORITY_TAIL_GRACE_POLLS=3`。子队列达到可用状态数后会生成 A/B skill，并在 tail grace 后接受 partial tail，保证无人值守队列能继续推进。partial tail 被接受后，已完成 states 继续有效；未完成题允许停止，作为该阶段缺失处理。
- skill 生成：bootstrap skill 由 `train-local --bootstrap-skill` 生成；A/B skill 由 Python 内的 `SkillCritic` + `SkillActor` 离线生成，不需要人工 tmux/Codex CLI 介入。
- run 目录匹配：trainer 会把 run_name 的分钟级前缀替换为实际秒级前缀，例如 `20260504_0110_...` 对应目录可能是 `20260504_010008_...`。子队列已按 run_name 后缀补了兼容匹配。
